# v1.8.10

This release makes every implicit state machine in the factory explicit, including the
issue and PR label machines, head-commit validity (stale verdicts and fix-round
refunds), the fix-round cap, the merge gate, the assignee pause, failure and
WIP recovery, dispatch handoffs, agent outcome classification, and the
vendored skill processes. The specifications live in `docs/state-machines/`
with a machine-readable index, and a new CI step (`tests/state_machines.py`)
fails if they drift from the workflows and labels they describe.

Also records the 2026-11-07 installer replay evidence (no behaviour
change).

No installer changes: nothing under `template/` changed, so existing installs
are unaffected. The floating `v1` tag moves to this release for consistency.

Changes since [v1.8.9](https://github.com/jonbaldie/software-factory/compare/v1.8.9...v1.8.10).
