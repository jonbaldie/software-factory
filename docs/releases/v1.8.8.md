# v1.8.8

This release hardens installation, issue handling, review and the scout.

- Preserve explicitly disabled setup commands across reinstalls. Refuse symlinked destinations and stop if repository variables cannot be read. Detect npm test scripts using JSON parsing.
- Stop implementation for closed issues, preserve completed work when publishing fails, and report a failed review handoff without retrying implementation.
- Check root repository policies in reviews. Recognize factory verdicts only when their marker leads the comment. Preserve pre-existing `.github/` changes during fixes.
- Ignore Markdown files and TODO markers in JavaScript strings. Check all issue titles when deduplicating scout tickets.
- Share trusted prompt construction and fail-fast test execution across factory stages.

Rerun the installer to update the copied workflows and prompts. The floating `v1` tag also supplies the installer and runner to existing users.

Changes since [v1.8.7](https://github.com/jonbaldie/software-factory/compare/v1.8.7...main).
