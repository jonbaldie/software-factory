# v1.8.9

The scout now distinguishes JavaScript and TypeScript comments from multiline template literals, strings, regular expressions, and JSX data. This prevents false TODO issues for parsed files. Some comment titles can change, so the scout may file a duplicate of an existing issue.

If the scout cannot parse a file, it warns and falls back to the previous line-by-line detection. That fallback can still mistake data for a TODO comment.

Rerun the installer to update the scout script and its bundled parser. The scout requires Node.js and Python 3.

Changes since [v1.8.8](https://github.com/jonbaldie/software-factory/compare/v1.8.8...v1.8.9).
